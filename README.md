# PlayTorrio PS4

Native PS4 homebrew project for GoldHEN 10.01. Source-of-truth for product features: [PlayTorrio V3](https://github.com/mghazalyh/ptv3). Independent build/toolchain; shared watchlist schema with private `torriodb`.

**Status:** Work in progress, not a tested PS4 streaming release. See `FEATURE_PARITY.md` for verified and pending features.

This is not a repackaging of the Flutter application. Official OpenOrbis toolchain is required for genuine `.pkg` output. No access keys or personal watchlist files are committed.
